How the lap comparison works

01

Circuit baseline

Each circuit has a reference lap time that sets the overall timing range for the simulation.

02

Driver pace offset

Each driver has a small simulated pace offset used only to create differences within the development model.

03

Circuit variation

Technical demand and circuit type influence the amount of lap-to-lap variation generated by the model.

04

Analysis

JavaScript calculates fastest lap, average pace, consistency, lap deltas and the overall comparison.

This is a development simulation. The values are illustrative and are not official Formula 1 timing data or performance predictions.
